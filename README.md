# SQL-Student-Management-Database
Student Management Database using SQLite for SQL Data Analysis Internship Task 1

Project Title 
Student Management Database Using SQLite 
Objective 
The objective of this project is to create a Student Management Database using SQLite and perform SQL 
queries to analyse student performance. This project helps in understanding how SQL can be used for data 
storage, retrieval, analysis, and updating records.

Tools Used 
• SQLite 
• DB Browser for SQLite 
• GitHub 
• LinkedIn 

Queries Performed 
1. Displayed all student records using the SELECT statement. 
2. Calculated the average score in Mathematics, Science, and English using the AVG() function. 
3. Identified the top-performing student based on total marks. 
4. Counted the number of students in each grade using GROUP BY and COUNT(). 
5. Calculated the average total score based on gender. 
6. Retrieved students who scored more than 80 marks in Mathematics. 
7. Updated a student's grade and verified the changes.
   
Conclusion 
This project provided hands-on experience in working with databases using SQLite. It improved my 
understanding of SQL concepts such as table creation, data insertion, filtering, aggregation, grouping, sorting, 
and updating records. Through this task, I gained practical knowledge of how SQL is used in data analysis and 
student performance evaluation.
